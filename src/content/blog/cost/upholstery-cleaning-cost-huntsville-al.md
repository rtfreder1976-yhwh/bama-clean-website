## What Determines Upholstery Cleaning Cost?

### Fabric Type

- **Microfiber:** Very common in Huntsville homes. Requires careful moisture control to avoid water rings.
- **Cotton and linen:** Absorb stains deeply. Usually safe for water-based cleaning.
- **Velvet:** Pile must be brushed during cleaning to prevent matting. Higher cost.
- **Leather:** Cleaning and conditioning, not extraction. Runs $100-$300 for a sofa.

### Soil Level

Light soil: standard pricing. Heavy pet odor, embedded food stains, or smoke: add $30-$60 per piece.

## The Fabric Code System

Every upholstered piece has a cleaning code tag under the seat cushion:

- **W** -- Water-based cleaning only
- **S** -- Solvent-based only
- **WS** -- Either method safe
- **X** -- Vacuum only

Professional cleaners read the code before touching the piece. Using the wrong method permanently damages fabric.
