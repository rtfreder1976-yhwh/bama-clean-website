## What Determines Upholstery Cleaning Cost?

**Fabric type:** Microfiber requires careful moisture control. Velvet requires pile brushing. Leather requires conditioning, not extraction ($100-$300 for a sofa).

**Soil level:** Light soil: standard pricing. Heavy pet odor or embedded food stains: add $30-$60 per piece.

## The Fabric Code System

Check the tag under the seat cushion:

- **W** -- Water-based cleaning only
- **S** -- Solvent-based only
- **WS** -- Either method safe
- **X** -- Vacuum only

Professional cleaners read the code before touching the piece.
